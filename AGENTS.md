# Agent instructions

This repo keeps one set of agent instructions, in [CLAUDE.md](CLAUDE.md). Read
that file — it applies to every agent working here, not just Claude Code.

The short version, because it is the part that breaks when ignored: parallel
threads work on this repo, so take work from GitHub issues, claim the issue
before touching anything, branch from `main` as `<agent>/<topic>`, never commit
to `main` or push to another thread's branch, and land via PR stating the
verification you actually ran. The director merges.
